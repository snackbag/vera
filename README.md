# Archived

The library has outgrown its original scope and many decisions are not up to par with our current quality. Due to time constraints, it is not possible to rewrite the entire library. Ultimately, the decision to archive this library was made. We will reassess this project in the future.

# Vera

Because UI should be simple.

Vera is a simple yet powerful UI library, currently developed for Fabric. Our wiki page is currently still under
construction. The Javadoc covers all methods.

## Features

- Various standard widgets
    - Checkboxes
    - Combo boxes
    - Labels
    - Text input
    - Images
    - Rectangles
    - Scroll boxes
    - Tabs
    - Easy creation of custom widgets
- Styling system written from the ground up
- Animation system and custom easings
- Layout system
- HUD-rendering
- General rendering QOL outside Vera apps
- App hierarchy
- Simple keybinding managing
- Docstrings everywhere
